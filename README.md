# Fluid Fabs

**AI-designed microfluidics, manufactured on demand.**

Fluid Fabs makes custom 3D-printed microfluidic chips more affordable for researchers. Explore our approach, applications, and work from the lab.

## Run locally

Install **Git, Node.js 24, and npm**, then run:

```bash
git clone https://github.com/danielzhong/Fluidica.git
cd Fluidica
npm ci
npm run dev
```

Open **http://localhost:4321**, or the address shown in your terminal. Press **Ctrl+C** in the terminal to stop the server.
